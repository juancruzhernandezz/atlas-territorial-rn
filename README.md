# Atlas territorial de Río Negro

Documento de trabajo (noviembre 2026) con los datos públicos de base del territorio rionegrino: población, salud, universidades, rutas, tren y proyectos de energía, con foco en la Ciudad Lineal del Alto Valle.

- Versión web: https://juancruzhernandezz.github.io/atlas-territorial-rn/
- Versión PDF: [atlas-territorial-rn-noviembre-2026.pdf](atlas-territorial-rn-noviembre-2026.pdf)

Fuentes: INDEC (Censo 2022), IGN, OEDE, portal del RIGI, OpenStreetMap y fuentes oficiales citadas en el documento.

Elaborado por Juan Cruz Hernández.
